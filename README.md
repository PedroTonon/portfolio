**Repositório:** https://github.com/PedroTonon/loja-online-sql

### Descrição

Projeto desenvolvido em PostgreSQL simulando o banco de dados de uma loja virtual. O projeto contempla modelagem relacional, criação de tabelas, inserção de dados e consultas SQL para manipulação e análise das informações.

### Tecnologias

- PostgreSQL
- SQL

### Destaques

- Modelagem de banco de dados relacional
- Chaves primárias e estrangeiras
- Relacionamentos entre tabelas
- Consultas com JOIN
- GROUP BY
- Funções de agregação
- Views
- Consultas analíticas
